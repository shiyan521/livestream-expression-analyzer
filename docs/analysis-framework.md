# 分析框架文档

本文档详细说明 Livestream Expression Analyzer 的 20 维度分析框架，包括标准层 15 个维度和深度层 5 个维度。

## 框架概览

```
分析框架
├── 标准层（15 维度）
│   ├── 执行摘要
│   ├── 核心指标
│   ├── 口癖分析
│   ├── 声学特征
│   ├── 语速分析
│   ├── 情绪状态
│   ├── 停顿分析
│   ├── 口癖热力图
│   ├── 互动分析
│   ├── 话题结构
│   ├── 每10分钟指标
│   ├── 最佳/最差表现
│   ├── 诊断
│   ├── 改善建议
│   └── 跨场对比
│
└── 深度层（5 维度）
    ├── 表达结构分析
    ├── 内容质量分析
    ├── 收尾困难分析
    ├── 认知负荷分析
    └── 即兴表达原理
```

---

## 标准层（15 维度）

### 1. 执行摘要

| 项目 | 说明 |
|------|------|
| **指标** | 综合评分（0-100）、表达水平评级 |
| **计算方法** | 六维度加权平均：音高表现力(15%) + 音量动态(15%) + 语速合理性(20%) + 流畅度(20%) + 发音清晰度(15%) + 停顿控制(15%) |
| **目标值** | 85分以上（优秀） |
| **评级标准** | 90+: 优秀 / 80-89: 良好 / 70-79: 待改善 / <70: 需重点训练 |

### 2. 核心指标

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 音高表现力 | 音高变化范围与表现力 | 基于音高标准差与变化频率评分 | 85+ |
| 音量动态 | 音量变化丰富度 | 基于动态范围(dB)与变异系数评分 | 80+ |
| 语速合理性 | 语速是否在合理范围 | 偏离推荐范围(300-360字/分)程度 | 80+ |
| 流畅度 | 表达流畅程度 | 基于口癖密度与碎片率综合评分 | 80+ |
| 发音清晰度 | 发音可懂度 | 基于声学特征与信噪比评分 | 90+ |
| 停顿控制 | 停顿频率与时长合理性 | 基于停顿分布与中位数评分 | 85+ |

展示方式：六维度雷达图

### 3. 口癖分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 核心口癖总数 | 所有核心口癖出现次数总和 | 逐词统计 | - |
| 核心口癖密度 | 每千字核心口癖数 | 核心口癖总数 / 总字数 * 1000 | <15/千字 |
| 全口癖密度 | 每千字所有口癖数（含延伸词） | 全口癖数 / 总字数 * 1000 | <60/千字 |
| 核心口癖分布 | 各核心口癖的出现次数 | 逐词统计并排序 | - |
| 延伸词分布 | 各延伸词的出现次数 | 逐词统计并排序 | - |
| 组合模式 | 口癖连用模式检测 | 相邻口癖组合检测 | - |

**口癖分类：**
- 核心口癖：对吧、呃、那个、或者说、样一个、比如说、这样一个、到底、嘛、就是说、呢、嗯、这个这个、吧
- 延伸词：这个、啊、那、就是、然后、可能、所以、的话、其实、还是

展示方式：水平柱状图（核心口癖 + 延伸词）

### 4. 声学特征

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 音高均值 | 平均基频频率(Hz) | librosa.pyin 提取 | 120-200Hz |
| 音高中位数 | 基频中位数(Hz) | 排序取中位数 | 100-180Hz |
| 音高标准差 | 音高波动程度 | 标准差计算 | 50-100Hz |
| 音量动态范围 | 最小到最大音量范围(dB) | RMS 能量计算 | >60dB |
| 音量变异系数 | 音量变化幅度 | 标准差/均值 | >0.5 |
| 发音清晰度 | 语音可懂度评分 | 基于信噪比与频谱特征 | 90+ |

展示方式：带进度条的评分卡片

### 5. 语速分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 平均语速 | 每分钟字数 | 总字数 / 说话时长(分) | 300-360字/分 |
| 中位语速 | 每分钟字数中位数 | 按分钟统计后取中位数 | 300-360字/分 |
| 语速标准差 | 语速波动程度 | 按分钟统计后计算标准差 | <80 |
| 变异系数 | 语速稳定性 | 标准差 / 均值 | <0.2 |
| 语速曲线 | 按分钟追踪的语速序列 | 每分钟字数 | 平稳波动 |

展示方式：折线图（含均值参考线）

### 6. 情绪状态

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 情绪曲线 | 情绪激活度变化 | 基于音高、音量、语速综合计算 | 稳中有升 |
| 情绪波动 | 情绪稳定性 | 曲线标准差 | 适中 |

展示方式：折线图（按2分钟窗口采样）

### 7. 停顿分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 停顿中位数 | 句间停顿中位数(秒) | 逐句间隔统计 | 0.8-1.2秒 |
| 短停顿(<1s) | 短停顿次数 | 间隔 < 1秒 | 60-70% |
| 中停顿(1-3s) | 中停顿次数 | 1秒 <= 间隔 < 3秒 | 20-25% |
| 长停顿(3-5s) | 长停顿次数 | 3秒 <= 间隔 < 5秒 | 5-10% |
| 超长停顿(>5s) | 超长停顿次数 | 间隔 >= 5秒 | <5% |

展示方式：环形图

### 8. 口癖热力图

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 每10分钟口癖密度 | 时间维度口癖分布 | 按10分钟窗口统计口癖密度 | 逐段下降 |
| 热点时段 | 口癖密度最高的时段 | 取密度最大值对应时段 | - |

展示方式：柱状图（颜色深浅表示密度高低）

### 9. 互动分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 目标说话人占比 | 主要说话人的发言时长占比 | 目标说话人时长 / 总时长 | >80% |
| 说话人切换次数 | 说话人切换频率 | 逐句检测说话人变化 | 适中 |
| 互动模式 | 问答/对话/独白模式 | 基于切换频率与时长分布 | - |

### 10. 话题结构

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 话题分段 | 按内容拆分话题段 | 基于语义聚类与时间间隔 | - |
| 话题时长 | 各话题段时长 | 逐段统计 | - |
| 话题口癖密度 | 各话题段口癖密度 | 逐段计算 | <3/千字 |
| 话题语速 | 各话题段平均语速 | 逐段计算 | 300-360字/分 |
| 话题评级 | 各话题段表现评级 | 基于口癖密度与语速综合评分 | 良好以上 |

展示方式：表格

### 11. 每10分钟指标

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 10分钟口癖密度 | 细粒度口癖分布 | 按10分钟窗口统计 | - |
| 10分钟语速 | 细粒度语速变化 | 按10分钟窗口统计 | - |
| 10分钟情绪 | 细粒度情绪变化 | 按10分钟窗口统计 | - |

### 12. 最佳/最差表现

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 最佳时段 | 综合表现最好的10分钟窗口 | 口癖密度最低 + 语速合理 | - |
| 最差时段 | 综合表现最差的10分钟窗口 | 口癖密度最高 + 语速异常 | - |
| 最佳话题 | 表现最好的话题段 | 口癖密度最低的话题 | - |
| 最差话题 | 表现最差的话题段 | 口癖密度最高的话题 | - |

### 13. 诊断

基于以上指标生成表达问题诊断报告，包括：
- 口癖问题：核心口癖密度是否偏高、哪些口癖最突出
- 语速问题：是否过快/过慢、波动是否过大
- 停顿问题：是否缺乏中长停顿
- 结构问题：收尾是否仓促、开场是否冗长

### 14. 改善建议

按优先级（P1/P2/P3）给出可执行的改善方案：

| 优先级 | 说明 | 格式 |
|--------|------|------|
| P1 | 最紧急的问题 | 诊断 + 行动方案 + 预期效果 |
| P2 | 次要改善点 | 诊断 + 行动方案 + 预期效果 |
| P3 | 长期优化方向 | 诊断 + 行动方案 + 预期效果 |

每个建议包含：
- **诊断** - 基于数据的问题描述
- **行动方案** - 2-3 个具体可执行的改善方法
- **预期效果** - 量化改善目标

### 15. 跨场对比

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 口癖密度趋势 | 跨场次口癖密度变化 | 逐场统计 | 持续下降 |
| 语速趋势 | 跨场次语速变化 | 逐场统计 | 趋于稳定 |
| 碎片率趋势 | 跨场次碎片率变化 | 逐场统计 | 持续下降 |
| 综合评分趋势 | 跨场次综合评分变化 | 逐场统计 | 持续上升 |

展示方式：多 Y 轴折线图

## 深度层（5 维度）

### 16. 表达结构分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 开头质量 | 开场5分钟的表达质量 | 口癖密度 + 语速合理性 + 情绪激活 | 良好以上 |
| 主体质量 | 主体部分的表达质量 | 加权综合评分 | 良好以上 |
| 结尾质量 | 收尾5分钟的表达质量 | 口癖密度 + 语速合理性 | 良好以上 |
| 结构完整性 | 开头-主体-结尾的完整性 | 三段评分方差 | 方差小 |

**分析要点：**
- 开场是否吸引了听众注意力
- 主体内容是否有清晰的逻辑结构
- 结尾是否有有力的总结

### 17. 内容质量分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 信息密度 | 单位时间内的有效信息量 | 有效内容字数 / 总时长 | 适中 |
| 逻辑连贯性 | 句间逻辑连接程度 | 连接词使用频率与分布 | 高 |
| 重复率 | 无意义重复内容占比 | 重复句子检测 | <10% |
| 举例频率 | 举例说明的频率 | 举例关键词检测 | 适中 |

### 18. 收尾困难分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 收尾口癖密度 | 收尾阶段的口癖密度 | 最后5分钟口癖密度 | <全场平均 |
| 收尾语速变化 | 收尾阶段语速变化 | 最后5分钟语速 vs 全场均值 | 无明显加速 |
| 收尾时长占比 | 收尾部分占总时长比例 | 收尾时长 / 总时长 | 5-10% |
| 收尾自控力指数 | 收尾阶段自控力评估 | 综合口癖+语速+停顿评分 | 80+ |

**典型问题：**
- 收尾口癖飙升（缺乏准备）
- 收尾语速加快（急于结束）
- 收尾过长（不知如何结束）

### 19. 认知负荷分析

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 话题切换负荷 | 话题切换时的表达质量变化 | 切换前后口癖密度差值 | 差值小 |
| 长时间表达负荷 | 长时间表达后的质量衰减 | 后半程 vs 前半程质量对比 | 衰减小 |
| 复杂话题负荷 | 复杂话题的表达质量 | 复杂话题段口癖密度 | <3/千字 |
| 疲劳指数 | 表达疲劳程度评估 | 基于语速下降+口癖上升综合计算 | 低 |

### 20. 即兴表达原理

基于即兴表达理论（Impromptu Speaking Principles）的评估：

| 指标 | 说明 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 即兴流畅度 | 即兴表达的流畅程度 | 无准备段落的口癖密度与语速 | 良好 |
| 即兴结构化 | 即兴表达的结构性 | PREP结构检测（观点-理由-例子-观点） | 结构清晰 |
| 即兴衔接 | 即兴段落的衔接质量 | 连接词使用与话题过渡 | 流畅 |
| 即兴自信度 | 即兴表达的自信程度 | 基于语速稳定性+音量稳定性 | 高 |

## 评分计算公式

### 综合评分

```
综合评分 = 音高表现力 * 0.15
        + 音量动态 * 0.15
        + 语速合理性 * 0.20
        + 流畅度 * 0.20
        + 发音清晰度 * 0.15
        + 停顿控制 * 0.15
```

### 流畅度评分

```
流畅度 = 100 - (核心口癖密度 * 1.5) - (碎片率 * 100 * 2)
```

### 语速合理性评分

```
语速偏差 = |平均语速 - 330| / 330
语速合理性 = 100 - (语速偏差 * 100) - (变异系数 * 100)
```

### 停顿控制评分

```
停顿控制 = 100 - |停顿中位数 - 1.0| * 30 - (短停顿占比 - 0.65) * 50
```
