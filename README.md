# Livestream Expression Analyzer

> 开源的直播/播客口头表达能力分析系统，20 个维度量化你的表达质量。
>
> 🛠 本项目使用 **Qoder AI 编程助手** 开发与持续迭代（详见[开发历程](#开发历程)）。

## 项目简介

Livestream Expression Analyzer 是一个开源的口头表达分析工具，专为直播主播、播客创作者、演讲者和培训师设计。通过上传音频文件，系统会自动进行语音转写、说话人分离、声学特征提取和多维度分析，生成一份详细的"表达体检报告"。

报告涵盖口癖检测、语速分析、声学特征、情绪追踪、话题表现等 20 个维度，并提供可执行的改善建议，帮助你持续提升口头表达能力。

## 功能特性

### 标准层 - 15 个分析维度

| 序号 | 维度 | 说明 |
|------|------|------|
| 1 | 执行摘要 | 综合评分与表达水平评级 |
| 2 | 核心指标 | 六维度雷达图（音高、音量、语速、流畅度、清晰度、停顿） |
| 3 | 口癖分析 | 核心口癖 + 延伸词检测，密度计算与组合模式 |
| 4 | 声学特征 | 音高(Hz)、音量动态范围(dB)、发音清晰度 |
| 5 | 语速分析 | 按分钟追踪语速曲线，均值/中位数/标准差/变异系数 |
| 6 | 情绪状态 | 情绪变化曲线追踪 |
| 7 | 停顿分析 | 短/中/长/超长停顿分布 |
| 8 | 口癖热力图 | 每10分钟口癖密度热力图 |
| 9 | 互动分析 | 说话人占比与互动模式 |
| 10 | 话题结构 | 按话题拆解表现差异 |
| 11 | 每10分钟指标 | 细粒度时间序列分析 |
| 12 | 最佳/最差表现 | 标记表现最好和最差的时段 |
| 13 | 诊断 | 基于数据的表达问题诊断 |
| 14 | 改善建议 | 分优先级的可执行改善方案 |
| 15 | 跨场对比 | 历史场次趋势追踪 |

### 深度层 - 5 个分析维度

| 序号 | 维度 | 说明 |
|------|------|------|
| 16 | 表达结构分析 | 开头-主体-结尾的结构完整性评估 |
| 17 | 内容质量分析 | 信息密度与逻辑连贯性 |
| 18 | 收尾困难分析 | 结尾阶段口癖飙升与自控力下降检测 |
| 19 | 认知负荷分析 | 话题切换时的认知负荷变化 |
| 20 | 即兴表达原理 | 基于即兴表达理论的评估 |

## 快速开始

### 1. Clone 项目

```bash
git clone https://github.com/your-org/livestream-expression-analyzer.git
cd livestream-expression-analyzer
```

### 2. 安装依赖

```bash
# 基础依赖
pip install -r requirements.txt

# 可选依赖（ASR 后端等）
pip install -r requirements-optional.txt
```

### 3. 启动服务

```bash
python web/app.py
```

打开浏览器访问 `http://localhost:5000` 即可使用。

## ASR 后端选择

本系统支持三种语音转文字（ASR）后端：

| 后端 | 说明 | 费用 | 准确度 | 安装方式 |
|------|------|------|--------|----------|
| **逐字稿导入** | 上传已有的逐字稿文件 | 免费 | 最高 | 无需安装 |
| **Whisper 本地** | 使用 openai-whisper 本地转写 | 免费 | 高 | `pip install openai-whisper` |
| **阿里云百炼** | 使用阿里云 ASR 服务 | 付费 | 最高 | 需申请 API Key |

### 逐字稿导入支持的格式（自动检测）

| 格式 | 示例 | 来源 |
|------|------|------|
| 腾讯会议段落式 | `施言   01:12` + 下一行内容（支持跨行合并） | 腾讯会议/直播平台转写导出 |
| 飞书妙记 | `[00:00:05] 李四` + 内容行 | 飞书妙记导出（含说话人+时间戳） |
| 标准单行 | `施言(01:12): 内容` | 通用转写文本 |
| JSON | `[{"speaker": "施言", "time": "02:55", "text": "..."}]` | 结构化逐字稿 |

详细配置说明请参考 [快速开始指南](docs/getting-started.md)。

## 开发历程

### 2026-08-09 · Qoder 迭代（Web 端接入真实分析管线）

本项目由产品创作者定义分析框架与业务逻辑，使用 **Qoder AI 编程助手**完成编码实现与持续迭代。本次迭代在 Qoder 中完成以下工作：

1. **逐字稿解析器升级**：支持腾讯会议段落式（`姓名 时间` + 跨行内容）、飞书妙记（`[HH:MM:SS] 说话人`）、标准单行及 JSON 四种真实世界格式的自动检测与解析，说话人自动编号，头部元信息自动过滤。
2. **Web 端接入真实分析管线**：`/api/analyze` 从 Demo 占位升级为真实分析——上传音频 + 逐字稿后，执行完整的三层分析（表达层 20 维度 + 内容层 + 认知层），不再返回预置 Demo 数据。
3. **报告数据适配器**：新增 `web/report_adapter.py`，将分析引擎的嵌套输出转换为报告页可视化结构，支持雷达图、口癖分布、情绪曲线、话题分段等全部图表。
4. **真实数据验证**：使用 0805 场次真实直播音频（125 分钟）与逐字稿完成端到端验证，分析结果与手动校准数据一致。
